# Literature Tools

This repository contains the reusable tooling used to organize and scrape the local literature vault.

Included:
- `_Preprocess/fetch_journal_keyword_batch.py`
- `_Preprocess/fetch_lawyers_courts_batch.py`
- `_Preprocess/journal_keyword_scraper_template.py`
- `_Preprocess/journal_keyword_scraper_template.example.toml`
- `_Preprocess/sync_obsidian_literature.py`

Excluded:
- PDFs
- Obsidian notes
- bibliographies
- local app state
